# Security Policy

## Supported versions

Security fixes are provided for the latest Marketplace release.

## Reporting a vulnerability

Please do not publish vulnerability details, credentials, private conversation
content, or proof-of-concept exploits in a public issue.

Use GitHub's **Report a vulnerability** button on this repository when private
vulnerability reporting is available. Otherwise, email
`tncontrolweb@gmail.com` with:

- the affected version;
- steps to reproduce;
- the expected impact; and
- the minimum sanitized logs or screenshots needed to investigate.

We will acknowledge the report, investigate it, and coordinate disclosure after
a fix is available.
